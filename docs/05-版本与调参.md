## 现场调参顺序

1. **选对脚本**：板型后缀（`_lsp`）+ 图传方案（`ap_mjpeg` / `rtsp`）。
2. **曝光**：对着赛场灯光调到球与凹槽对比清晰，重启确认已保存。
3. **检测门槛**：漏检→降 `confidence_threshold`（0.30→0.20）；误检→升。
4. **坐标验证**：串口助手看 `capture_x`，球在槽中心应≈112，两端极限≈0/223。
5. **图传验收**：手机/VLC 能看画面；比赛要求录制的用 RTSP + VLC 录制。
6. **MCU 联调**：OLED `Camera:OK` 后跑 T4/Q5，误差大再回看 1350 侧 `docs/06` 调参。

## 与 1350 固件的边界

| 侧 | 负责 |
|----|------|
| K230（本仓库） | 检测钢球、图传、发 `capture_x` |
| MCU（1350） | 球 PID/前馈、循迹、步进摆杆、停车 |

坐标标定（100=O 点）在 **MCU 侧**换算；视觉端只发 0–223 原始值。
改模型输入尺寸（224）会连带改坐标量程，两头都要动。
