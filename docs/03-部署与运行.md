# 03 · 部署与运行

## 前置条件

### 1. 固件

| 板型 | 固件 |
|------|------|
| 亚博 | 原厂 CanMV K230（出厂即可） |
| 庐山派 | `CanMV_K230_LCKFB_*.img`（[wiki.lckfb.com](https://wiki.lockfb.com/zh-hans/lushan-pi-k230/quick-start.html) 或官方 wiki） |

### 2. AI 模型

SD 卡根目录放 INT8 量化 kmodel（224×224 输入，单类 `gangzhu`）：

```
/sdcard/best_v21.kmodel
```

自训练模型转换：

```bash
# 导出 ONNX
yolo export model=best.pt format=onnx imgsz=224 opset=12 simplify=True
# nncase 转 kmodel（需 conda 环境 nncase + nncase-kpu）
python convert_to_kmodel.py
```

### 3. SD 卡布局

```
/sdcard/
├── best_v21.kmodel      # AI 模型（必须）
├── exposure.conf        # 曝光存档（v7+ 自动生成）
└── main.py              # 改名后开机自启
```

## 运行方式

### IDE 运行（调试）

1. USB 连板（亚博 micro-USB / 庐山派 Type-C）。
2. 打开 IDE（亚博=CanMV IDE；庐山派=VS Code CanMV 插件或 IDE Web）。
3. 连接串口设备，打开对应板型的脚本，点运行。

### 独立运行（比赛）

1. 选定脚本改名为 `main.py`。
2. 拷到 SD 卡根目录（与 kmodel 并列）。
3. 上电自动运行（脚本内 `startup_delay_ms=1000` 等待系统就绪）。

## 开机后自检

1. **LCD**：显示相机画面 + 检测框 + `FPS:xx N:x`，中央有 URL（AP 方案）。
2. **串口**：有球时每 ~30ms 发一帧 11 字节坐标（见协议文档）。
3. **MCU 侧**：OLED 该显示 `Camera:OK`（1350 工程 T4/Q5 页）。

## 曝光调节

- 触摸屏上下滑动调节曝光（步进 `exposure_step_us=1000`）。
- v7+ 自动保存到 `/sdcard/exposure.conf`，下次开机恢复。
- 赛场灯光下先手动调到球与槽对比清晰再锁定。

## 常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| 绿屏闪烁（庐山派） | 跑了亚博脚本（CSI 不对） | 换 `_lsp` 版本 |
| 花屏（庐山派） | 分辨率配成 640×480 | 用 `_lsp`（800×480，`Display.init` 在 `bind_layer` 前） |
| 无画面 | 排线松（庐山派 FPC 本身斜插） | 重新压紧排线 |
| WiFi 流打不开 | 没连上热点 | 先连 SSID 再开 URL |
| MCU 收不到坐标 | 引脚/波特率不对 | 亚博=GPIO9/UART1，庐山派=GPIO11/UART2，均 115200 8N1 |
| 不开机 | 固件不对或 SD 卡差 | 庐山派必须 LCKFB 固件；换优质 SD |
| 曝光每次开机重置 | 版本 < v7 | 用 v7+ |
| `draw_string_advanced Deprecated` 刷屏 | 新固件废弃该 API | 用 v17+（`draw_string`） |
| 庐山派供电不足 | 3.1" 屏 ~700mA | 供电 Hub 或 GH1.25 2P 辅助供电 |

## 性能参考（亚博 GC2093 @ 224×224）

| 指标 | 值 |
|------|-----|
| NPU 推理 | ~12ms/帧 |
| 实际帧率 | ~70fps（限频后 75fps） |
| AP 图传 | 320×180 @ 8fps |
| 串口上报 | ~33Hz（30ms 间隔） |
| 整机功耗 | ~700mA（带屏） |
