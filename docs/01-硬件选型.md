# 01 · 硬件选型（两种相机）

本工程支持两块 K230 开发板。**感光器件同为 GC2093**，差异在 CSI 通道、屏幕、串口——
脚本必须用对板型，否则花屏/无画面/串口不通。

## 对照表

| 项 | 亚博 Yahboom | 庐山派 LCKFB（脚本后缀 `_lsp`） |
|----|--------------|--------------------------------|
| 型号 | K230 CanMV v1.8 | LCKFB 庐山派 K230 |
| 感光器件 | GC2093 | GC2093 |
| CSI | 默认 CSI，`Sensor()` | CSI2，`Sensor(id=2)` |
| 屏幕 | ST7701 640×480 | ST7701 800×480 |
| 串口 | UART1：GPIO9(TX)/GPIO10(RX) | UART2：GPIO11(TX)/GPIO12(RX) |
| 固件 | 原厂 CanMV K230 | `CanMV_K230_LCKFB_*.img`（[wiki.lckfb.com](https://wiki.lckfb.com/zh-hans/lushan-pi-k230/quick-start.html)） |
| IDE | CanMV IDE 桌面版 | VS Code CanMV 插件 或 CanMV IDE Web |
| USB | micro-USB | Type-C |
| 供电 | — | 3.1" 屏约 700mA，建议供电 Hub 或 GH1.25 2P 辅助供电 |
| 40Pin | — | 兼容树莓派排针 |
| 脚本示例 | `gangqiujiance_ap_mjpeg_v20.py` | `gangqiujiance_ap_mjpeg_v20_lsp.py` |

## 文件命名约定

```
gangqiujiance_ap_mjpeg_v{N}.py       亚博 · AP+MJPEG 图传
gangqiujiance_ap_mjpeg_v{N}_lsp.py   庐山派 · AP+MJPEG 图传
gangqiujiance_v{N}_rtsp.py           亚博 · RTSP 图传
gangqiujiance_v{N}_rtsp_lsp.py       庐山派 · RTSP 图传
```

**选脚本先看后缀**：`_lsp` = 庐山派，无后缀 = 亚博。用错的典型后果：

- 庐山派跑亚博脚本 → 绿屏闪烁（CSI 通道不对）或花屏（分辨率 640≠800）
- 亚博跑 `_lsp` 脚本 → `Sensor(id=2)` 无此 CSI，无画面

## 关键代码差异

```python
# 亚博
pipeline.sensor = Sensor(fps=75)
display_size = [640, 480]
uart = YbUart(baudrate=115200)                    # UART1

# 庐山派
pipeline.sensor = Sensor(id=2, fps=75)            # CSI2
display_size = [800, 480]
uart = MachineUART(MachineUART.UART2, baudrate=115200,
                   tx=11, rx=12)                  # UART2
```

## 接线到 MCU（MSPM0）

| 板型 | K230 引脚 | MCU 端（1350 工程） |
|------|-----------|---------------------|
| 亚博 | GPIO9 UART1 TX | PB3（UART3 RX） |
| 庐山派 | GPIO11 UART2 TX | PB3（UART3 RX） |
| 两板 | GND | GND |

**电平 3.3V**，严禁 5V 串口直连 K230 GPIO。MCU TX（PB2）接 K230 RX 为可选双向。

## 相机安装

赛题要求：摄像头固定在摆杆凹槽上方，画面覆盖整个摆杆，能看清钢球滚动轨迹。
本工程 AI 输入为 224×224，`display_source_crop=[420,0,1080,1080]` 从 GC2093 的
1920×1080 原图取中间方区；安装时让摆杆尽量落在画面中部。
